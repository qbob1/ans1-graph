Key Features & Interactions

Keyboard Shortcuts

  • Ctrl/Cmd + K: Toggle control panel open/close
  • Escape: Close control panel if open

Mouse Interactions

  • Scroll Wheel: Zoom in/out on the graph
  • Click + Drag (background): Pan the graph
  • Click + Drag (node): Move individual nodes
  • Click ⚙️ button: Open/close control panel

Visual Design

  • Color Scheme: Purple gradient (#667eea to #764ba2) for headers
  • Floating UI: Control panel appears above graph with shadow
  • Smooth Animations: Panel slides in/out with transitions
  • Status Messages: Green (success) or red (error) notifications
  • Responsive: Adapts to window resize automatically

Component Architecture

  • Web Components: Custom elements with Shadow DOM
  • <asn1-graph-viewer>: Encapsulated graph visualization
  • <asn1-control-panel>: Encapsulated control UI
  • Event-driven: Components communicate via CustomEvents
  • Framework-agnostic: Works in React, Vue, Angular, or vanilla HTML
